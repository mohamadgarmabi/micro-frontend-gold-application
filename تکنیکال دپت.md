## 1. Critical

### 1.1 Auth and OTP are demo-only
- **Paths:** `apps/application-pwa/src/modules/auth/hooks/auth.hook.ts`, `otp.hook.ts`, `config/security.constants.ts` (`DEMO_OTP_CODE = '123456'`), `auth/apis/index.ts`
- **Issue:** Login/OTP never hit a server; synthetic `aurum-demo-token-*`; fixed OTP is usable in a production-shaped app.
- **Action:** Wire real auth APIs; strip demo paths from production builds.

### 1.2 API defaults to jsonplaceholder
- **Paths:** `apps/application-pwa/src/config/api.ts`, `apps/application-pwa/vite.config.ts`, `apps/website/src/config/api.ts`, `packages/apis/src/config/store.ts`
- **Issue:** Without `VITE_APP_API_URL`, apps fall back to a public sample host.
- **Action:** Fail closed without env; point at the real backend.

### 1.3 Market layer is fully mocked
- **Paths:** `apps/application-pwa/src/modules/market/utils/data.ts` (`Math.random`, `SPOT_PRICE`, `recentActivity`); `market/apis` is comment-only
- **Issue:** Home, chart, and trade all run on static mock data.
- **Action:** Real price API + store; remove random series generation.

### 1.4 Django backend is not gold-domain aligned
- **Paths:** `apps/backend/**` (shop/catalog models and README)
- **Issue:** Generic ecommerce scaffold, disconnected from PWA auth/market/trade/WebAuthn; not an Nx project.
- **Action:** Define gold-domain APIs, or remove/split until scope is clear.

### 1.5 Fake identity and balances in product UI
- **Paths:** `profile/views/profile-view/index.tsx` (`Marcus Chen`, sample email); `home.hook.ts` / `profile.hook.ts` (hardcoded balances)
- **Issue:** User identity and money figures are not API-backed.
- **Action:** Load profile/wallet from session or backend.

## 2. High

### 2.1 Legacy token bridge after HeroUI migration
- **Paths:** `packages/design-system/src/legacy-aliases.css`, `styles.css`, `heroui-theme.css`
- **Issue:** Old `gold-*` / `neutral-*` / `brand-*` Tailwind names still map onto HeroUI CSS vars via the design-system entry.
- **Action:** Finish class migration in apps, then delete `legacy-aliases.css`.

### 2.2 Undefined `--ds-*` CSS variables
- **Paths:** `chart-view/index.tsx`, `chart.hook.ts`, `theme-selector.hook.ts`; only `--ds-font-*` exists in `fonts.css`
- **Issue:** `--ds-brand`, `--ds-danger`, `--ds-border`, etc. are referenced but not defined.
- **Action:** Map to HeroUI/theme tokens or define `--ds-*` in one place.

### 2.3 Leftover Base UI tooling/deps
- **Paths:** `scripts/generate-base-ui-components.mjs`, `@base-ui/react`, `base-ui.css`, federation generator comments
- **Issue:** Components are HeroUI-based, but Base UI generators and deps remain.
- **Action:** Remove or retarget generators for the current stack.

### 2.4 Empty PWA module API scaffolds
- **Paths:** `modules/{home,chart,trade,profile,options,market,shell,auth}/apis/index.ts`
- **Issue:** Folder layout exists; almost no real clients (except WebAuthn re-exports).
- **Action:** Implement clients or delete scaffolds until needed.

### 2.5 Options price alerts are non-functional
- **Paths:** `options.hook.ts`, `options-view/index.tsx` (empty `onValueChange`, hardcoded `value={['3,400']}`)
- **Issue:** Save only toasts; input not wired; violates UI-only TSX rules.
- **Action:** Bind value/handlers in the hook, or hide the section until ready.

### 2.6 WebAuthn / device security are client-only
- **Paths:** `auth/utils/webauthn.utils.ts` (`localStorage`), `packages/apis/src/webauthn/**`, `security.utils.ts` (PIN/2FA in localStorage)
- **Issue:** Credential metadata and PIN live in the browser; API targets non-existent backend routes.
- **Action:** Server-side WebAuthn RP; document device-lock threat model clearly.

### 2.7 Committed `storybook-static` build
- **Paths:** `apps/storybook/storybook-static/**` (not gitignored)
- **Issue:** Built assets bloat the repo and go stale.
- **Action:** Gitignore + untrack; publish via CI artifacts.

### 2.8 Stack split: Vue website vs React PWA
- **Paths:** `apps/website` (Vue + MF), `apps/application-pwa` (TanStack React)
- **Issue:** Shared `@gold/apis`, no shared UI; Module Federation adds complexity.
- **Action:** Decide: keep Vue marketing thin, or unify on React and drop MF remotes.

### 2.9 Legacy `aurum-*` CSS namespace
- **Paths:** `apps/application-pwa/src/styles.css` and consumers in auth/chart/profile
- **Issue:** Pre-rebrand naming still drives chrome and view transitions.
- **Action:** Rename to product tokens / move into design-system.

### 2.10 Demo posts API on jsonplaceholder
- **Paths:** `packages/apis/src/posts/**`, `apps/website/src/components/PostsList.vue`
- **Issue:** Sample CRUD outside the gold domain.
- **Action:** Replace with domain clients or isolate as a docs-only sample.

### 2.11 No tests for apps and design-system
- **Paths:** Nx targets for `application-pwa`, `website`, `design-system`, `storybook` lack `test`; backend `tests.py` is empty
- **Issue:** Coverage is a handful of package unit tests (vitest mid-rollout).
- **Action:** Start with PWA auth/security hooks and critical utils; gate in CI.

### 2.12 Committed Module Federation diagnostics
- **Paths:** `packages/shared-components/.mf/diagnostics/latest.json`
- **Issue:** Local diagnostic noise in git; signals broken MF type generation.
- **Action:** Gitignore `.mf/`; fix or disable typegen until stable.

## 3. Medium

### 3.1 Export-convention violations (bottom-of-file only)
- **Paths:** Many files under `packages/apis`, shared-components `*.type.ts`, Storybook stories
- **Issue:** Inline `export` on declarations instead of bottom exports (AGENTS.md).
- **Action:** Add/enforce lint rule; migrate hot paths first.

### 3.2 Duplicate Card wrappers / inconsistent imports
- **Paths:** `shared-components/.../card`, `shell/components/card.tsx`; mixed imports across modules
- **Issue:** Extra pass-through layer.
- **Action:** Import `@gold/shared-components/card` everywhere; delete shell wrapper.

### 3.3 Placeholder stores
- **Paths:** `home/stores` and similar stubs under chart/trade/profile/options/market
- **Issue:** Files exist while state lives in hooks/constants.
- **Action:** Introduce stores with real data, or delete dead files.

### 3.4 Profile menu items have no handlers
- **Paths:** `profile.hook.ts` + `profile-view`
- **Issue:** Security / alerts / history / KYC rows do nothing.
- **Action:** Add `onSelect` + routes, or mark disabled with copy.

### 3.5 Quick actions route to placeholders
- **Paths:** `home.hook.ts` (withdraw/delivery → `/profile`, invoices → `/chart`)
- **Issue:** Navigation is stubbed.
- **Action:** Point to real flows or remove until implemented.

### 3.6 Root `typecheck` misses projects
- **Paths:** root `package.json` → only pwa + shared-components + form
- **Issue:** `apis`, `website`, etc. are outside the scripted path.
- **Action:** Use `nx run-many -t typecheck`.

### 3.7 Vitest rollout is thin
- **Paths:** `vitest.config.base.ts`, package vitest configs, ~4 tests
- **Issue:** Good start; incomplete gate and coverage.
- **Action:** Stabilize configs; cover cookie/auth and form schema.

### 3.8 JS-readable auth cookies
- **Paths:** `packages/apis/src/auth/cookie.ts`
- **Issue:** Tokens via `document.cookie`; XSS equals session theft.
- **Action:** Prefer HttpOnly cookies from backend/BFF, or short-lived tokens + refresh.

### 3.9 Incomplete i18n / hardcoded English
- **Paths:** profile view, auth placeholders, `PostsList.vue`
- **Issue:** Bypasses `i18n.en.ts` / `i18n.fa.ts`.
- **Action:** Move all user-facing strings to message keys or API data.

### 3.10 Website still uses legacy `gold-*` classes
- **Paths:** `HomePage.vue`, `PostsList.vue`, `SiteNav.vue`, …
- **Issue:** Depends on legacy-aliases; not aligned with PWA Typography usage.
- **Action:** Switch to current theme tokens; prepare for alias removal.

### 3.11 Backend outside shared Nx/CI
- **Paths:** `apps/backend`
- **Issue:** Docker/Django island without shared targets.
- **Action:** Add Nx project + CI jobs, or move to a separate repo with a clear contract.

### 3.12 design-system has no lint/typecheck/test
- **Paths:** `packages/design-system/package.json`
- **Issue:** CSS-only package with no quality gates.
- **Action:** Add stylelint/format check and an Nx lint target.

### 3.13 Website has no shared i18n layer
- **Paths:** FA marketing pages + English Posts demo panel
- **Issue:** Inconsistent language; no ICU/namespaces.
- **Action:** Add website i18n, or keep marketing FA-only and remove the English demo.

### 3.14 Prettier + prettier-plugin-tailwindcss instability
- **Paths:** root formatting tooling (`e.charAt is not a function` on TSX/CSS)
- **Issue:** `format` / `format:check` can fail on otherwise valid files.
- **Action:** Upgrade/pin Prettier + plugin versions; verify in CI.
